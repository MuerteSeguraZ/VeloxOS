# VeloxOS

VeloxOS is an operating system project built to be fast, clean, and practical.

## What is VeloxOS?

VeloxOS is a WIP operating system focused on speed, simplicity, and control.  
Not trying to be bloated or overly complicated, the goal is to build a solid foundation that's easy to understand, extend, and improve.

## Status

VeloxOS is under active development.  
Expect incomplete features, rough edges, and frequent changes while the core system evolves.

## Getting Started

### Prerequisites

To build and run VeloxOS, you’ll typically need:

- A compatible development environment.
- An x86_64 toolchain.
- A bootloader or emulator setup.
- Basic Unix-like build tools.

### Build

```sh
git clone https://github.com/MuerteSeguraZ/VeloxOS.git
cd VeloxOS
make
```

If your setup uses a different build system or script, replace the command above with the one used in the repository.

### Run

If you're testing in an emulator:

```sh
make run
```

Or boot the generated image in your preferred virtual machine or test environment.
